# Changelog

## Unreleased

- The game runs in the browser (Vite, TypeScript); the Electron app is gone.
- Start screen with four levels: Easy, Medium, Hard and Huge, each with its own number of hearts.
- Lives as hearts: every revealed mine costs half a heart.
- Revealed mines count like flags when clicking a number.
- Game over: an explosion wave reveals every mine; a win sets off a golden wave and confetti.
- Sound effects with a mute button that the browser remembers.
- End screens for winning and losing with Play again and Change level, instead of alerts.
- Restart and New game buttons, a working flag counter and a favicon.
- Deployment to GitHub Pages after a green verify run.
